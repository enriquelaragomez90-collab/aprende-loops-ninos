# 🐍 Aprende Bucles con Python

Programa para niños que enseña qué son los bucles (`for` y `while`) con lecciones interactivas, dibujos, una cuenta regresiva de cohete, un juego de adivinar el número y un mini-quiz.

## Cómo usarlo

```
python aprende_loops.py
```

Solo necesita Python 3, no hay que instalar nada más.
